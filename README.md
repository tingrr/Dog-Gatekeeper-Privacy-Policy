# 🐕 Dog Gatekeeper

> A cute pixel art Samoyed guards your screen when you've been doom-scrolling too long — time for a break!

## ✨ Features

- **⏱ Smart Timer** — Automatically tracks your browsing time on social media sites
- **🐕 Dog Reminder** — When time's up, an adorable pixel Samoyed appears on screen with a countdown
- **⚙️ Customizable** — Set your own usage time limit and break duration
- **🌐 Multi-Site Support** — 12 popular platforms pre-configured, plus add any custom domain
- **🌍 10 Languages** — English, Chinese (Simplified & Traditional), Japanese, Korean, French, Spanish, Portuguese, Indonesian, Vietnamese
- **📱 Responsive** — Works seamlessly on all screen sizes

### Default Monitored Sites

Twitter/X · YouTube · Facebook · Reddit · Threads · Bluesky · Instagram · TikTok · Weibo · Bilibili · Douyin

You can toggle any site on/off and add custom domains.

## 🛡️ Privacy Policy

**Effective Date:** June 12, 2026

### 1. Information Collection and Use

Dog Gatekeeper does not collect, store, or transmit any personal data or personally identifiable information (PII) to external servers. All data required for the extension to function, including user-defined settings, break intervals, and blocked website lists, is stored strictly on the user's local device using the browser's extension storage API.

### 2. Permissions Justification

- **Storage**: Used solely to save your custom blocklists and reminder configurations locally.
- **Tabs / ActiveTab / Scripting**: Used locally to detect if the currently active website matches your custom blocklist, and to display the rest reminder overlay on that tab. No browsing history is saved, tracked, or sent anywhere.
- **Alarms**: Used as a local background timer to trigger your rest breaks.

### 3. Data Transfer and Third Parties

We do not sell, trade, or transfer any user data to third parties. There are no tracking scripts, analytics, or external advertisements embedded within the extension.

### 4. Changes to This Privacy Policy

We may update our Privacy Policy from time to time. Any changes will be posted on this page.

## 📝 Technical Details

- **Chrome Extension Manifest V3** — built with the latest extension platform
- **100% Client-Side** — no backend server required, all data stays on your device
- **Programmatic Injection** — content scripts are injected only on monitored sites for optimal performance
- **Pixel Art SVG** — the Samoyed is drawn with inline SVG, no external image dependencies
- **Chrome i18n API** — standard `_locales` structure for multi-language support
